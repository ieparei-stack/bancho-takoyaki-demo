# 반쵸의 타코야키 포장마차 — 〈반쵸 더 셰프〉 기획 데모

**▶ 바로 플레이: https://ieparei-stack.github.io/bancho-takoyaki-demo/**
(브라우저에서 바로 실행 · 마우스 전용 · 소리 켜고 · 약 15분)

〈데이브 더 다이버〉의 반쵸가 사흘 동안 타코야키 포장마차를 맡는다는 설정의 2D 데모입니다.
손님은 사람 입맛이 아닌 요괴들이고, 반쵸는 그 입맛을 단서 삼아 레시피 밖의 재료로 맛을 찾아갑니다.

## 하루의 흐름

| 때 | 하는 일 |
|---|---|
| 아침 | 메모판에서 오늘의 예약을 읽고, 장보기에서 재료와 도구를 산다 |
| 개점 | 가스불을 켜고 종을 걸어 울린다 |
| 영업 | 반죽 짜기 → 재료 넣기 → 1차·2차 뒤집기 → 후네 담기 → 토핑·건네기. 판을 건넬 때마다 하늘이 저문다 |
| 마감 | 불을 끄고 종을 내린다 |
| 밤 | 영업 일지에 도장을 찍고, 손님이 남긴 이야기와 선물을 받는다 |

## 조작

- **반죽 짜기**: 구멍을 누르고 있다가 반죽이 초록 눈금에 닿으면 뗀다 (도-미-솔-도)
- **재료 넣기**: 재료판에서 문어·재료를 끌어 구멍 가운데에 놓고, 다 됐으면 "모두 완료!"
- **뒤집기**: 테두리가 노릇해지고 알이 들썩이면 반 바퀴, 김이 오르면 한 바퀴 돌리고 뗀다
- **후네 담기**: 구멍을 누른 채 후네 쪽으로 휙 튕긴다
- **건네기**: 소스·가쓰오부시를 뿌리고 후네를 위로 끌어 손님에게

## 만든 방식

- 바닐라 JavaScript + SVG, 빌드 없음. `반쵸 더 셰프 데모 실행.html`을 더블클릭해도 실행됩니다
- 판정 값·재료·손님·대사는 모두 [`data.js`](data.js)에 있고, 게임이 이 파일을 읽어 동작합니다
