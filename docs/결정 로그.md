| 항목 | 사용자 답 |

### 실제 조리 시간 조사 (사용자 요청)
- 반죽 → 1차 뒤집기 약 2~3.5분, 1차 → 2차 약 1~2분, 한 판 5~10분. 출처는 SPEC 5-1.
- 사용자 질문 "8초 굽는 게 맞아?" → 실제는 약 3분, 게임 값은 압축값이라고 설명.

### 플레이 피드백 (2026-10-11, 원문 요지)
1. 흰색 → 갈색 → 검정 변화가 실제 타코야키답지 않다 — 실제 변화를 보고 고도화 필요
2. "지금인가?" 힌트 부족 — 반죽 디스펜서의 반죽이 줄어드는 정도 + 초록 목표선, 작은 눈금 3 + 큰 눈금 1, 움찔움찔 네 번째에 멈추기, 도-미-솔-도
3. 소스·후레이크 고도화 (후순위)
4. 판이 타코야키를 굽고 있다는 걸 인지할 수 없다
5. 기포가 올라왔을 때 뒤집어야 한다는 게 전달이 안 된다 — 실제 타코야키라면?
6. 티켓 후순위로 넣을지 고민
7. 제출한 판의 "성적표" — 알마다 무슨 메뉴인지, 얼마짜리인지
