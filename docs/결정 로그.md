### 1단계 수치
| 항목 | 사용자 답 |
|---|---|
| 목표 홀드 | 사용자가 BPM을 물음 ("하나당 1~2초?"). Claude 추천 120 BPM / 홀드 1000 ms → **"해보고 정하자"**. 시작값으로 두고 1단계 플레이 후 확정 |
| 판정 창 | **퍼펙트 ±50 / 굿 ±120** (초안 ±80/±160에서 좁힘) |
| 초과 시 | **일정 시간 후 자동 종료**, 시점은 **굿 창 끝 직후 (+120 ms)** |
| 소리 곡선 | "잘 모르겠다, 할 때 해보자" → 1단계에서 후보를 들어보고 결정 |

### 실제 조리 시간 조사 (사용자 요청)
- 반죽 → 1차 뒤집기 약 2~3.5분, 1차 → 2차 약 1~2분, 한 판 5~10분. 출처는 SPEC 5-1.
- 사용자 질문 "8초 굽는 게 맞아?" → 실제는 약 3분, 게임 값은 압축값이라고 설명.

### 2단계 수치
| 항목 | 사용자 답 |
|---|---|
| 굽기 큐 | **1차 : 2차 = 2 : 1 비율만 확정**, 절대값은 해보고 정함 (시작값 8 s / +4 s) |
| 뒤집기 창 | **퍼펙트 ±150 / 굿 ±300** (초안) |
| 2차 조건 | **330° + 720 °/s** (초안) |
| 1차 후 표정 | 성공 = **기대하는 표정**, 실패 = **불안한 표정** |
| 최종 표정 | **두 판정 합산** (점수표는 2단계 인터뷰) |

### 이 인터뷰로 바뀐 초안 항목
- 원칙 1: "3초 무조작 금지" → "손이 오래 놀지 않게" (3초는 방향성)
- 문어 넣기: "판정 없음 + 넣기 전 다음 단계 잠김" → "위치 판정 있음 + 잠김 없음, 문어 없이도 뒤집기 가능"
- 1차 굽기 큐: TBD → 구멍별, 그 구멍 반죽 시점 기준
- 2차 굽기 큐: 2.0 s → 1차와 2:1 비율 (시작값 +4 s)
- 짜기 판정 창: ±80/±160 → ±50/±120
- 짜기 목표: 900 ms → 시작값 1000 ms (120 BPM), 플레이 후 확정
- 뒤집기: 판 단위 암시 → 구멍별
- 접시로: 1회 드래그 → 구멍별 6회
- 손님: 매출 방식 미정 → 표정별 개당 가격, 조리와 서빙 분리
