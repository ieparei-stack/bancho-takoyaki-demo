## 0. 기획 의도 — 내가 하고 싶었던 핵심 (사용자, 2026-10-12)

모든 작업의 우선순위는 이 목록으로 판단한다. 기획서·기획 노트·영상의 뼈대도 여기서 나온다.

1. **하루의 감각** — 가장 큰 핵심. 아침에는 재료를 준비하는 감각, 낮에는 굽는 감각, 밤에는 하루를 마감하는 감각.
   그래서 하루 마감(결과창, 영업 일지)과 오전에 계속 공을 들인다.
2. **미니게임을 재미있게** — 요리가 주가 되면 미니게임이 가장 중요하다.
   닌텐도 〈리듬 세상〉을 가져오고 싶었다: **시각 힌트 + 소리로 박자를 맞추고 있다는 감각.**
   반죽 짜기(도-미-솔-도)에서는 잘 됐다고 생각한다. 다른 단계에 어떻게 넣을지는 아직 모르겠다. 데모에서는 한계도 있다.
3. **레시피 발견 — 반쵸다움** — 반쵸는 뻔하게 만들지 않는 캐릭터다. **특이한 재료로 어떻게든 맛을 만들어 내는 것**이 반쵸의 핵심.
   손님을 요괴로 정한 이유: 사람 입맛이 아니라서 특이한 재료·입맛과 상호작용할 수 있고, 그래서 레시피 발견이 생긴다.
   → 할 일 후보: **지금 재료가 뻔한 것뿐이다. 특이한 재료가 있으면 좋겠다.**
4. **진짜 타코야키를 굽는 느낌** (별개로) — 굽는 과정 자체가 타코야키다워야 한다.

> Claude 메모: 한 문장으로 묶는다면 "하루"가 틀이고, 그 안의 세 기둥이 **아침 준비 / 리듬 손맛 / 요괴 손님과 레시피 발견**이다.
> 기획서·영상은 "하루" 한 문장 + 세 기둥마다 장면 하나로 압축할 수 있다. 루트슈터의 "같은 AR이라도 룰만으로 다른 총"과 같은 방식.

## 1. 대사집 손질 — 사용자가 직접

data.js의 모든 대사·문구를 사용자가 직접 손본다. Claude는 요청할 때만 고친다.
Claude가 찾은 "AI 티" 나는 곳 (참고용):

**패턴**: 말버릇을 모든 줄에 기계적으로 붙임 / 음식 광고 카피 문체 / 기획자 목소리가 캐릭터 입으로 샘 / 공식 같은 농담 / 따옴표 강조

**강함**
- `menus` 숨은 요리 `desc` 3개 — "문어 맛을 깨운다", "달콤한 디저트 같은 한 알", "감칠맛 덩어리"
- `letters.review.say.allPerfect` — "겉은 바삭, 속은 촉촉! 굽기가 완벽해요 👍"
- 너구리 `love` — "바다가 입 안에서 터지는군"
- 참새 `love` — "딱 내 스타일"
- `dialogue.night2` 까마귀 동생 "먹고 나서 하는 말을 잘 들어 봐… 티가 나거든" / 형님 "쪽지에도 뭘 좋아하는지는 안 쓸 거다" (게임 설명조)
- `dialogue.night1` 참새 — "특이한" 따옴표

**중간**
- `letters.funny` 전부 — "(주문한 적 없음)", "신메뉴인가요?", "소스 온천", "개성 넘치는", "사장보다 낫다"(사장 = 반쵸라 논리 어긋남)
- `letters.result.aceTitle` "에이스" / `letters.settle.bestNone` "쉬어 가는 날"
- 참새 1일차 1판 "초심을 잃었네?" / `dialogue.night3` 편지 자리 "자네만의 타코야키"

**약함 (말버릇)**: 참새 "짹" 14줄 중 9줄 / 까마귀 형님·너구리 "…" 시작 남발 / 참새·동생 "~" 과다

**안 보이는 문구**: `letters.reply`(옛 4단계 답장, 미사용), `customers.reactions` 기본 대사(모든 손님이 자기 대사가 있어 안 보임)

장인의 편지(`letters.days[0]`)는 사용자 원문이라 대상 아님.

## 2. 인게임 성장 (강화)

사용자 구상:
- **반죽**: 짜는 시간 단축(지금 목표 홀드 1.5 s, 도-미-솔-도 4박) / **한 줄(3구멍) 동시 짜기**
- **재료 넣기**: 재료 하나 클릭 → **6알 동시 넣기**, 켜고 끌 수 있게
- **뒤집기**: 실력이 드러나는 손맛 → 강화 없이 그대로
- **후네 담기**: 강화 여부 미정 (말이 끊겨 확인 필요)
- **토핑**: 연출용 그대로 유지

Claude 의견:
- 강화를 **돈으로 사면** "재료 vs 강화" 선택이 생겨 "돈에 비용이 없다" 문제가 같이 풀린다.
- 기획 노트용 원칙: **"반복 노동은 성장으로 덜어 주고, 실력이 드러나는 손맛(뒤집기)은 남긴다."**
- 6알 동시 넣기는 3일차 실험(알마다 다른 재료)과 충돌 → 켜고 끄기가 꼭 필요.
- 토핑은 "등급 없는 연출 단계"라고 기획 노트에 한 줄 남기면 의도로 읽힌다.

정할 것:
1. 강화를 얻는 방법 — 돈으로 사기 / 손님 선물 / 섞기
2. 언제 사나(밤·아침), 사흘 동안 몇 개
3. 짜기 단축의 리듬(박자 빠르게 / 3박), 한 줄 짜기 판정(세 알 같은 판정?)
4. 6알 동시 넣기 때 문어 점수(가운데 놓기 정확도)를 어떻게
5. 후네 담기 강화 여부

## 3. 오전 — "하루가 간다"는 느낌

사용자 고민: 오전이 상점에서 금방 지나가서 하루가 안 느껴진다. **하루가 이 데모의 핵심.**

결정(잠정):
- **재료 손질 미니게임은 생략** — 단, 기획서·기획 노트에 **"중요하다고 보지만 데모 볼륨상 과감히 생략했다"**를 반드시 남긴다.
- 예외로 **문어 손질 하나만** 남기는 쪽으로 생각 중 (매일 쓰는 기본 재료, 썬 조각 = 재료판 문어 칸 6조각).
- 고민 중: **산 재료를 바구니에서 재료판(칸 나뉜 그릇)으로 직접 옮겨 담는 세팅.** 지금 준비 단계 카드 3장 고르기를 손 동작으로 바꾸는 것. 사용자 "별론가?" 반신반의 / Claude는 찬성 쪽(하루 3번 끌기라 볼륨 거의 안 늘고, "고르기"가 "가게 차리기"로 보임). 산 재료가 3개보다 많을 때 귀찮음으로 느껴질지는 해 봐야 앎.

Claude 제안 (길이보다 대비·의식·시간 흐름):
1. **개점 의식** — 노렌 걸기·가스불 켜기·기름 바르기 같은 한 동작짜리, 실패 없음. 지금 "시작!" 글자 대체
2. **영업 중 시간 흐름** — 손님마다 하늘이 오후 → 해 질 녘 → 저녁, 제등이 하나씩 켜짐, 새소리 → 풀벌레
3. **메모 쌓이기 (정보 수집)** — 예약 카드를 바로 띄우지 말고 한쪽에 메모·편지가 쌓여 있어 직접 열어 오늘 손님 확인. 예약 말고 넣을 것(어제 후기, 손님 소문 등) 정할 것

추천 순서: 강화 + 돈 연결 → 메모 쌓이기 → 개점 의식·시간 흐름 → 문어 손질·옮겨 담기

## 4. 그 밖에 미뤄 둔 것

- **기획 노트 + 로그 JSON** — 결과 화면의 "기획 노트 보기" 버튼은 있는데 내용이 없다. 그 사람의 실제 플레이(산 재료·본 단서·발견)를 근거로 설계 의도를 보여 주는 화면 → 기획 역량을 드러내는 데 가장 효과 큼
- **돈 밸런싱** — 지금 2일차에 재료를 다 살 수 있어 선택이 고민이 안 됨 (강화 도입과 같이)
- **숨은 요리 보상** — 발견해도 바뀌는 게 없음 (비싸게 팔림 ×1.5 / 다음 날 손님이 찾아옴 등)
- 잣 손맛(빨리 탐) 눈에 보이게, 싫은 맛 암시 문구, 안 쓰는 4단계 결산 데이터 정리
- 9단계 포장: AI 이미지 교체, 소리 다듬기, 다시 하기, 한 파일 제출본, README
