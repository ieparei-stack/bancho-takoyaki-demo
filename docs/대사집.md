# 대사집 — 화면에 나오는 모든 문구 (2026-10-12, 커밋 `6aa7b16` 기준)

## 쓰는 법

- **고친 문구** 칸에 적으면 Claude가 `data.js`에 옮긴다. 비워 두면 그대로 둔다. `data.js`를 직접 고쳐도 된다.
- 표기 규칙
  - `\n` = 줄바꿈 (대화창·편지·말풍선)
  - `**글자**` = 강조 (주황·굵게). 재료 힌트·잣 등에 쓴다
  - `{손님}` `{값}` `{메뉴}` `{빠진 맛}` `{싫은 맛}` `{재료}` `{n}` `{m}` `{all}` = 자동으로 채워지는 자리. **그대로 남겨야 한다**
- 길이 감
  - 대화창: 한 줄 약 35자, 두 줄까지 편함 (넘으면 자동 줄바꿈)
  - 말풍선(손님 머리 위): **한 줄**, 약 25자까지 (길면 말풍선이 넓어진다)
  - 예약 쪽지: 한 장에 약 40자
  - 후기 게시물 문장: 한 줄 약 22자 (넘으면 자동 줄바꿈)
  - 영업 일지 대사 인용: 두 줄까지(약 40자), 넘으면 잘린다
- ⚠ = Claude가 "AI 티"가 난다고 본 곳 (어제 보고). 참고만.
- 화자 표기: 참새 🐦 / 까마귀 형님 🐦‍⬛(과묵) / 까마귀 동생 🐦‍⬛(촐싹) / 너구리 🦝(미식가, 말 짧음) / 반쵸("…", "음."만) / 편지(장인)

## 손님 반응 대사 (판을 건넨 직후 말풍선 + 후기 게시물 첫 줄 + 영업 일지 인용)

**어떤 반응이 나오나** (위에서부터 먼저 맞는 것):
1. **망함(flop)** — 실패한 알(덜 익음·탐·빈 알)이 3개 이상
2. **반함(love)** — 그 손님이 특히 좋아하는 메뉴가 한 알이라도 있음 → `{메뉴}` = 그 메뉴 이름
3. **싫은 맛(dislike)** — 싫어하는 맛이 든 알이 있음 → `{싫은 맛}` = "매운 게", "단 게" 등 (자동 강조)
4. **아쉬움(lack)** — 좋아하는 맛이 든 알이 하나도 없음 → `{빠진 맛}` = 좋아하는 맛 중 가장 적게 든 것 (자동 강조, 단서)
5. **맛있다(good)** — 좋아하는 맛 든 알이 1~3개 → `{빠진 맛}` (단서)
6. **최고(best)** — 좋아하는 맛 든 알이 4개 이상

손님 취향: 참새 = 고소함·짭조름 좋아함, 매콤함 싫어함, 좋아하는 메뉴 잣 타코야키 / 까마귀 형제 = 단맛·시원함, 매콤함 싫어함, 형님 배 타코야키·동생 배잣 타코야키 / 너구리 = 감칠맛·짭조름, 단맛 싫어함, 새우파 타코야키
